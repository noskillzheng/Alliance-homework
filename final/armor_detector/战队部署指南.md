## 3️⃣ 现场调参

### ① 相机参数（15分钟）

**文件**：`config/camera_params.yaml`

```yaml
camera:
  exposure_time: 5000    # 画面太暗→增大，过曝→减小
  gain: 10.1             # 噪点多→减小，太暗→增大
  gamma: 0.7             # 对比度调整（0.5-0.9）
```

**快速调整**：
- 装甲板看不清 → `exposure_time: 8000`
- 背景太亮 → `exposure_time: 3000`
- 性能不够 → 降低分辨率到 640x480

### ⚙️ 选择器参数（新功能）

**文件**：`config/detector_params.yaml`

```yaml
detector:
  selection:
    use_prediction_gating: true  # 启用预测门控
    gating_iou_min: 0.15         # IoU门限（减小更严格）
    gating_center_max_px: 60     # 中心距门限（像素）
```

**调整说明**：
- 误选反光/噪点 → 提高 `gating_iou_min` 到 0.25
- 快速运动易丢 → 放大 `gating_center_max_px` 到 80
- 关闭门控 → `use_prediction_gating: false`

### ② 检测参数（10分钟）

**文件**：`config/detector_params.yaml`

```yaml
detector:
  target_color: "red"              # 切换目标：red/blue
  binary_threshold: 80             # 仅作fallback（Otsu启用时）
  threshold:                       # v2.0+ Otsu自适应
    use_otsu: true                 # 推荐启用
    mode: "roi"                    # global/roi
  light:
    min_area: 30.0                 # 远距离检测不到→降低(20)
```

**调试流程（v2.1+优化）**：
1. 按 `d` 键打开调试模式，查看二值化图像
2. 装甲板灯条应为白色，背景为黑色
3. **Otsu启用后**：阈值自动调整，几乎无需手动改`binary_threshold`
4. **占比过滤启用**：大块白光和稀疏噪点会自动过滤，绿框减少属正常
5. 若全黑/全白 → 检查`min_threshold`/`max_threshold`保护范围
6. 若阈值跳动 → 提高`temporal_smooth`到0.9
7. 验收：Armors ≥ 1 且稳定，误识别少

### ③ 卡尔曼参数（5分钟）

**文件**：`config/kalman_params.yaml`

```yaml
kalman:
  prediction_time: 0.5             # 预测时间（秒）
  adaptive:
    fading_factor: 1.05            # 预测滞后→增大(1.08)
  process_noise:
    vx: 2.0                        # 预测滞后→增大(3.0)
    vy: 2.0
  measurement_noise:
    x: 3.0                         # 预测抖动→增大(5.0)
    y: 3.0
```

**问题速查**：
- 预测滞后 → 增大 `fading_factor` 或 `process_noise.vx/vy`
- 预测抖动 → 增大 `measurement_noise.x/y`
- 尺寸发散/负值 → 启用 `use_log_scale: true`
- 遮挡恢复慢 → 启用 `adaptive.enabled: true`

**v2.0 高级功能**：
```yaml
# 已默认开启，如有问题可关闭
use_variable_dt: true      # 帧率波动时预测更准
use_log_scale: true        # 尺寸永不为负，抖动↓50%
adaptive.enabled: true     # 自动适应环境变化
```

## 6️⃣ 常见问题

### Q1：相机打不开
```bash
# 检查连接
lsusb | grep -i hik

# 设置库路径
export LD_LIBRARY_PATH=/opt/MVS/lib/64:$LD_LIBRARY_PATH
./armor_detector

# 或使用sudo
sudo ./armor_detector
```

### Q2：找不到配置文件
```bash
# 确保从正确目录运行
cd /home/zheng/Alli/final/armor_detector/build
./armor_detector

# 或从项目根目录
cd /home/zheng/Alli/final/armor_detector
./build/armor_detector
```

### Q3：Armors一直为0
1. 按 `d` 查看调试图像
2. 灯条不是白色 → 调整 `camera.exposure_time`
3. 灯条是白色但不检测 → 降低 `detector.binary_threshold`

### Q4：跟踪易丢失或跳到反光（v2.0）
```yaml
# config/detector_params.yaml
detector:
  selection:
    use_prediction_gating: true     # 启用预测门控
    gating_iou_min: 0.15            # 提高到0.25更严格
    gating_center_max_px: 60        # 放大到80更宽松
```

### Q5：框抖动严重（v2.0）
```yaml
# config/visualizer_params.yaml
visualizer:
  smooth:
    enabled: true
    ema_alpha: 0.5     # 从0.35提高到0.5，更平滑
```

### Q6：APPROACHING/RETREATING闪烁（v2.0）
```yaml
# config/visualizer_params.yaml
visualizer:
  depth:
    hysteresis:
      in: 0.10         # 从0.06提高
      out: 0.05        # 从0.03提高
    hold_time: 0.3     # 从0.2提高
```

### Q7：尺寸跟踪不稳定
```yaml
# config/kalman_params.yaml
kalman:
  use_log_scale: true         # 务必启用（v2.0核心）
  process_noise:
    w: 3.0                    # 从5.0降低
    h: 3.0
```

### Q8：Otsu阈值跳动（v2.0+）
```yaml
# config/detector_params.yaml
detector:
  threshold:
    temporal_smooth: 0.9      # 从0.7提高，更平滑
    min_threshold: 50         # 提高下界
```

### Q9：光照变化检测失效（v2.0+）
```yaml
# 先尝试启用Otsu
detector:
  threshold:
    use_otsu: true
    mode: "roi"               # 或"global"

# 若ROI模式不稳，改用global
mode: "global"
```

### Q10：大量反光/白光被误识别（v2.1+）
**症状**：强反光环境下，大块白光、金属反光被识别为灯条

**解决**：已内置占比过滤，自动处理。如仍有问题：
1. 检查终端输出：`找到 X 个有效灯条`，数量应合理（<15）
2. 按 `d` 查看绿色框是否标记大片区域
3. 若误识别仍多，降低相机增益或曝光时间

**无需手动调参**（v2.1已自动优化）
