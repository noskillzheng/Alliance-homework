## 🎯 性能调优 - 只需改4个参数

打开 `config/optimizer_config.yaml`，找到 `performance` 部分：

```yaml
performance:
  time_safety_factor: 1.02      # 时间安全系数
  velocity_utilization: 0.95    # 速度利用率
  waypoint_velocity_ratio: 0.90 # 段间速度保持率
  min_segment_time: 0.3         # 最小段时间
```

### 参数速查表

| 参数 | 当前值 | 作用 | 想要更快→ | 想要更稳→ |
|------|--------|------|-----------|----------|
| time_safety_factor | 1.02 | 控制总时间 | ⬇️ 减小到1.01 | ⬆️ 增加到1.10 |
| velocity_utilization | 0.95 | 控制速度 | ⬆️ 增加到0.98 | ⬇️ 减小到0.85 |
| waypoint_velocity_ratio | 0.90 | 控制连续性 | ⬆️ 增加到0.95 | ⬇️ 减小到0.80 |
| min_segment_time | 0.3 | 最短段时间 | ⬇️ 保持0.3 | ⬆️ 增加到0.5 |

## 🔧 调优流程

### 步骤1: 选择基础配置
复制上述预设方案到 `config/optimizer_config.yaml`

### 步骤2: 运行测试
```bash
cd build
./sentry_trajectory_planner
```

### 步骤3: 观察结果
注意看输出中的约束检查：
```
段 0:
  最大速度: 0.4856 m/s [✓]
  最大加速度: 0.7599 m/s² [✓]
```

### 步骤4: 调整参数

#### 如果看到 [✗] (约束违反):
```yaml
# 增加安全系数
time_safety_factor: 1.02 → 1.05
```

#### 如果太慢（总时间 > 18秒）:
```yaml
# 减小安全系数，提高利用率
time_safety_factor: 1.10 → 1.05
velocity_utilization: 0.80 → 0.90
```

#### 如果运动不流畅（有停顿）:
```yaml
# 提高段间速度保持
waypoint_velocity_ratio: 0.80 → 0.90
```

### 步骤5: 可视化验证
```bash
python3 ../scripts/visualize_trajectory.py
```

## ❓ 常见问题

### Q1: 修改配置后需要重新编译吗？

**不需要！** 只有修改以下内容才需要重新编译：
- 路径点坐标（src/main.cpp）
- 源代码（.cpp / .hpp文件）

修改 `config/optimizer_config.yaml` 直接运行即可。

---

### Q2: 如何得到最快速度？

1. 打开 `config/optimizer_config.yaml`
2. 设置极限性能参数：
   ```yaml
   performance:
     time_safety_factor: 1.01
     velocity_utilization: 0.98
     waypoint_velocity_ratio: 0.95
   ```
3. 运行并检查是否有 [✗]
4. 如有违反，微调参数

---

### Q3: 出现约束违反怎么办？

看到 `[✗]` 时：
```yaml
# 方法1: 增加时间安全系数
time_safety_factor: 1.02 → 1.05

# 方法2: 降低速度利用率
velocity_utilization: 0.95 → 0.90

# 方法3: 两者都调
```

---

### Q4: 如何让运动更平滑？

```yaml
# 增加段间速度保持率
waypoint_velocity_ratio: 0.85 → 0.90

# 适当增加安全系数
time_safety_factor: 1.02 → 1.05
```

## 💡 使用技巧

### 技巧1: 快速切换配置

在配置文件底部已提供多种预设，复制到 `performance` 部分即可。

### 技巧2: 边界条件的妙用

如果机器人已在运动中，可设置初始速度：
```yaml
boundary_conditions:
  initial:
    velocity: [0.5, 0.0]  # 当前速度
```

### 技巧3: 调参顺序

推荐顺序：
1. 先调 `time_safety_factor` (影响整体时间)
2. 再调 `velocity_utilization` (影响速度)
3. 最后微调 `waypoint_velocity_ratio` (影响连续性)
