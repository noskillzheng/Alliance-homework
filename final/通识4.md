

## 2025 赛季英雄：方案选择、测试计划与进度规划

### 开源复盘与参考建议
- **推荐关注的队伍与方向**
  - **华南理工（SCUT）**: 舵轮底盘运动学与标定流程、云台抗扰控制、热量限幅管理与发射节律、整车状态机与安全联锁。
  - **南方科技（SUSTech）**: 自研控制框架（如任务模块化/消息总线风格）、自瞄追踪与弹道解算的工程化落地、裁判系统数据闭环。
  - **广东工业（GDUT）**: 结构轻量化与可维护性、双级拨弹抗卡与退弹策略、极限条件下的散热与热管理策略。
  - **香港科技（HKUST）**: 高速视觉链路与延迟治理、定位与姿态融合（IMU+轮速+视觉）、高抛弹道与站位预设库。
- **建议复盘切入点**
  - **代码结构**: 控制回路频率层级（1 kHz电机环/100-200 Hz姿态环/30-100 Hz策略）、任务调度与消息总线。
  - **自瞄链路**: 相机标定/畸变矫正、ROI/多目标管理、跟踪滤波、预测与延迟补偿。
  - **弹道解算**: 飞轮标定曲线、空气阻力与升阻模型、热量/命中概率综合代价函数。
  - **底盘与云台**: 小陀螺解耦、随动/锁头切换与死区、舵轮零位标定与逆/正解自检。
  - **可靠性**: 拨弹卡弹检测（电流/编码器微动/光电中断）、异常复位与“软单发”、故障降级策略。

### 方案选择（含激进方案与理由）
| 模块/功能大致方案 | 优先级 | 理由（规则/24赛季亮点） |
|---|---|---|
| 底盘：四舵轮全向（小陀螺稳定射击、姿态解耦） | P0 | 争夺点位与机动换位核心能力；24赛季多支强队四舵轮英雄小陀螺稳定输出表现亮眼。 |
| 舵轮标定与运动学库：零位快速自检+在线微调 | P0 | 赛中维护效率与精度稳定性；顶队标定流程成熟、恢复快。 |
| 云台：两轴（Yaw皮带减速+Pitch直驱/大模数齿） | P0 | 刚度与抗冲击兼顾、易维护；24赛季高命中队伍普遍选型类似。 |
| 发射机构：42 mm 双摩擦轮、独立闭环、热量限幅节律 | P0 | 符合热量规则，维持持续输出与瞬时爆发；热管理是得分上限关键。 |
| 供弹：双级拨弹+光电中断/编码器双冗余卡弹检测 | P0 | 可靠性第一，卡弹零容忍；24赛季强队多传感融合退弹。 |
| 传感器：高品质IMU+120fps相机（全局快门优先） | P0 | 低延迟与抗抖动，直接提升命中率与稳定性。 |
| 自瞄与跟踪：Armor检测（轻量YOLO/字典匹配）+KF/UKF | P0 | 识别+跟踪是基础生产力；多队已工程化稳定。 |
| 弹道解算：空气阻力模型+在线标定（速度-落点曲线） | P0 | 远距离与高抛可信度来源；24赛季远程压制表现相关。 |
| 通讯：裁判系统数据闭环+多通道冗余（UART/CAN） | P0 | 热量/装甲伤害/弹速闭环必备；通讯稳定性=可战时长。 |
| 控制架构：上位机（Orin NX/Nano）+下位机（H7）+RTOS | P0 | 分频控制、隔离风险；24赛季主流稳定栈。 |
| 驾驶交互：手操优先级管理+模式切换（锁头/随动/小陀螺） | P0 | 驾驶容错高，训练效率高；强队标配。 |
| 定位融合：IMU+轮速+视觉（PnP/AprilTag可选） | P1 | 站位与预瞄更稳；室内漂移可控。 |
| 视觉延迟治理：时间同步（PTP）+时戳外推补偿 | P1 | 命中率关键环节，顶队常用。 |
| 高抛/吊射解算（两解/无解判定+安全角域） | P1 | 地形/掩体压制增益高；多队已有尝试。 |
| 雷达辅助吊射（友军/场边雷达坐标融合） | P2 | 激进高收益；适合特定地图位形压制。 |
| 供弹高速模式（高弹速配套）+退弹自救流程 | P1 | 爆发轮次内最大化有效弹；24赛季实战必要。 |
| 热管理策略：期望DPS与热量积分联合调度 | P1 | 防过热断崖，提升有效DPS；强队亮点之一。 |
| 结构：发射与云台隔振+快速拆装维护设计 | P1 | 训练-比赛高频维护需求；可用性拉满。 |
| 电源：24V系统为主；可选飞轮升压至36V（若规则允许） | P2 | 激进提弹速但带来EMI与可靠性风险；需明确规则边界。 |
| “视觉自动兑矿/协同上岛”（与工程协作接口） | P3 | 协同收益可观但跨车复杂；保留接口、晚期择机。 |

- 激进方案与保底对策
  - **雷达辅助吊射（P2）** → 保底：纯视觉高抛+预设点位库；触发放弃条件：T-6周仍无法在三处典型点位内达到>70%首发命中率或延迟>120 ms。
  - **飞轮升压36V（P2）** → 保底：全24V+优化入射角与包覆率；放弃条件：T-8周出现EMI影响传感/通讯或升压模块温升不可控。
  - **定位融合（P1）** → 保底：无全局定位，仅局部预瞄与相对跟随；放弃条件：T-5周定位RMS误差>15 cm且偶发>30 cm。
  - **“自动兑矿/上岛协同”（P3）** → 保底：手动协同与简单宏指令；放弃条件：T-4周跨车通讯不稳定或安全联锁未完备。
  - **高速供弹模式（P1）** → 保底：标准供弹+节律发射；放弃条件：T-6周卡弹>0.5%或热管理联动不稳定。

### 测试计划（按依赖顺序与时间预估）
| 测试内容 | 阶段性目标 | 测试的方法 | 预计投入时间 |
|---|---|---|---|
| 硬件上电与线缆检查 | 电源/极性/接地/EMI合规 | 万用表/示波器/分路上电、热像排查 | 0.5 天 |
| 下位机驱动Bring-up（CAN/电机/IMU） | 电机可控、IMU零偏<阈值 | 单元测试、记录电流/速度/零偏曲线 | 1.5 天 |
| 舵轮零位标定与运动学验证 | 直线/圆轨迹误差<2% | 打印航迹、闭环里程计对比 | 2 天 |
| 云台编码器/限位/回零 | 安全联锁可用 | 低速扫角、软硬限位联测 | 0.5 天 |
| 云台姿态闭环（含扰动） | 阶跃<5%超调、整定时间<250 ms | 步进、扫频、敲击扰动 | 1 天 |
| 飞轮转速闭环与曲线标定 | 稳态误差<1%、转速恢复<150 ms | 磁电/光电测速、阶跃恢复测试 | 1 天 |
| 供弹与卡弹检测/退弹流程 | 连发卡弹≤0.2% | 光电+编码器比对、异常注入 | 1 天 |
| 裁判系统对接与热管理联动 | 不过热、DPS按设定分配 | 模拟高强度连发、热量积分校验 | 0.5 天 |
| 相机/IMU时间同步 | 时戳对齐误差<3 ms | LED闪烁/陀螺动作同步测试 | 0.5 天 |
| 目标检测精度/延迟 | mAP>0.9（自数据集）、端到端延迟<80 ms | 数据集评估、实枪端到端测时 | 2 天 |
| 跟踪与预测（含延迟补偿） | 目标丢失<5%、预测误差<装甲宽/4 | 轨迹回放与实测对比 | 1 天 |
| 弹道解算（平射+高抛） | 50/70/90%分段命中达标 | 靶场定距标定、在线修正拟合 | 2 天 |
| 小陀螺随动与云台解耦 | 旋转射击命中不显著下降 | 圆台位姿测试、环靶命中率 | 1 天 |
| 定位融合（可选） | 局部RMS<10 cm | 回环与标签标定、闭环评估 | 2 天 |
| 雷达辅助吊射（可选） | 三点位首发命中>70% | 坐标对齐、两解筛选与安全角域 | 2-3 天 |
| 系统级耐久与热稳定 | 1000 发无故障、温升可控 | 连续射击与机动混合工况 | 1 天 |
| 驾驶训练与策略验证 | 驾驶动作库与模式切换成熟 | 情景脚本训练与回放复盘 | 3-5 天 |

说明：
- 时间为净投入保守估计；并行项可交叉执行（如数据集制作与结构维护）。
- 每一关设“放行门槛”，未达标不进入下一环节，避免后期返工。

### 进度规划（仿照你的时间线风格）
- 2024.10-2024.11：规则精读与方案冻结；建立仿真与数据集管线；下位机框架搭建与电机/IMU驱动通。
- 2024.12：云台与发射机构机械定型与加工；供弹样机；视觉标定流程打通；期末周安排最小可用链路（MVP）：手动射击+基础随动。
- 2025.1：整车装配与线束；云台/飞轮/供弹联调；热管理联动；底盘运动学标定；MVP 实车可打靶。
- 2025.2：自瞄检测+跟踪+延迟补偿闭环；平射弹道标定；小陀螺随动联动；连发与退弹稳定性打磨。
- 2025.2-2025.3：定位融合（可选）与预设点位库；高抛弹道与安全角域；驾驶交互完善（模式/优先级/宏操作）。
- 2025.3-2025.4：标准化场地回归测试；对抗脚本化训练；风险清单收口与备件清单冻结。
- 2025.4（冲刺-1）：雷达辅助吊射验证（若选）；不达标按“保底对策”回退；供弹高速模式A/B对比保留收益更高者。
- 2025.5（冲刺-2）：系统耐久/热稳定压力测试；全队联动演练（含协同上岛接口演示）；文档与参数固化、镜像与参数包封版。
- 2025.5.26-赛事周：只做修复，不做新增；备件/参数双份；驾驶与裁判沟通演练；每日健康检查（紧固/清灰/标定复核）。

### 备注
- **“激进”项**全部有清晰放弃阈值与回退路径，确保不拖累主线命中率与可靠性。
- 以**“可靠性优先、命中率第二、扩展能力第三”**的顺序推进；测试门槛前置，避免堆积技术债。
