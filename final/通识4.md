# 2026赛季英雄机器人研发方案
（今天中午刷B站看到官方有26赛季规则的一些解读，出于英雄在家狙基地的公式基本被粉碎了本来要写25的方案凭着主观想法决定写26的。我认为英雄的定位在该赛季应该作出变动，不再过度追求吊射能力，大枪痿成这样不如带着步兵去前排绞肉。这样也可以逼着对方的英雄不得不放弃吊射来跟你对线或者躲到家里面。至于战术是否激进的问题，反正两边都是修塔大师，低压局对方只是更难杀，我们没有输的道理。高压局强攻没攻过导致崩了，那守家貌似也没有希望赢。开始想象交开局冲过来3个步兵，两个17mm口径的，还有一个42mm口径的，在你家里把移动的活物都咬了一遍然后大摇大摆的走了。所谓修塔不过是凌迟的时候需要砍的刀数多了一些而已，较难改变结局。而就经济而言，虽然进攻方要被迫付出更多的资源来支持进攻，但是能量单元的供应能力较上赛季的矿石机制来说，要达到等效的兑换经济门槛降低。凭靠基础的等级兑换基本就足够支持进攻需求，而且对面如果被压在家里，本身也很难有什么经济优势。打好水平相当的对局是提高比赛成绩的关键，容易发现的是26版本的调整就是为了增强机器人之间的对抗交互，凡具备在远程不通过与敌人交互便能左右大局的设定（无人机和吊射流英雄）统统被墙建。对于英雄这种开始出现多种定位可能的兵种，在这个赛季，多一分进攻主动性，便能在双方互相拉扯的对局里多一分优势。（针对对方会不断修前哨的问题，不成熟的想法是交给烧饼和无人机，步兵和英雄尽可能压住中心区域。而且无人机大胃袋也萎了，不如集中起来去打不断复活的前哨战）



## 团队与资源（假定）

- 团队配置：机械×2、电控×2、视觉（弹性加入）
- 资源：预算充足；可复用上季硬件/代码（计划优化：云台电机/编码器、发射轮、底盘防撞/登岛构件）
- 平台：STM32H7 主控 + 双CAN 分总线；Jetson Orin Nano/NX + TensorRT；工业相机 + 高速镜头

- 能力目标：

  - 全流程合规（射速/热量/功率/冲撞），并具备异常自动回退保底模式。

## 激进方案与保底对策

- 激进A（弱化吊射）：默认关闭毫米波融合，仅保留视觉-only 吊射兜底
  - 保底：视觉-only（轨迹预测+EKF），近距优先策略常开。
  - 放弃条件（针对雷达辅助融合）：A/B两周命中率提升 < 5% 或延迟 > 60 ms 即永久关闭融合。
- 激进B：端到端弹道 ML 校准（小模型拟合风/阻力动态项）
  - 保底：分段查表 + 线性微校正。
  - 放弃条件：至 2025.1 中相对查表命中率提升 < 5% 或推理耗时 > 2 ms。
- 激进C：Orin 多模型并行（装甲+防抖+去雾）
  - 保底：单模型时分复用 + ROI 调度。
  - 放弃条件：2025.2 前整机功耗/热限导致 FPS < 50。

触发放弃即 All-in 保底；T+3天完成参数与接口切换（统一模块接口已在架构期约束）。

测试顺序：
1) 底盘基础 → 2) 坡道/飞坡 → 3) 落地抗扰 → 4) 机动映射 → 5) 动作库 → 6) 云台 → 7) 发射 → 8) 弹道（短距优先） → 9) 视觉PnP → 10) 近距自瞄 → 11) 融合EKF → 12) 合规监控 → 13) 通信 → 14) 系统压测

## 附录 参数项建议

- 相机参数
  - 分辨率：宽、高；帧率；曝光（微秒）、增益
- 外参（右手系，单位米/弧度）
  - 相机→云台：平移t（x,y,z）、欧拉角rpy（Z-Y-X）
  - 云台→底盘：平移t、欧拉角rpy
- 检测器参数
  - 模式：hybrid / classic / yolo
  - YOLO：引擎路径、置信阈值、IOU阈值
  - 传统：HSV阈值、最小面积、最小长宽比
- 跟踪与触发
  - KF：位置过程噪声、速度过程噪声、测量噪声
  - 触发：驻留时间、目标切换防抖时间
- 弹道参数
  - 初速v0、空气阻力系数
  - 温度/转速分段补偿表（温区→转速修正）
- 云台控制
  - Yaw/Pitch PID与前馈；机械限位角度
- 通信
  - CAN分总线编号（运动/射控）；UDP回传与接收端口

回放工具：按时戳重建链路（检测→PnP→融合→弹道→指令），输出命中偏差与延迟瀑布图。

##  模块接口与数据

- 检测模块
  - 输入：图像帧
  - 输出：目标集合（包含类别、置信度、边界框、四角点、质心）
- PnP与外参模块
  - 输入：目标四角点、相机内参与畸变、相机到云台外参
  - 输出：目标在相机坐标系的位姿
- 融合模块（EKF/UKF）
  - 输入：视觉位姿、IMU、里程计、可选雷达
  - 输出：目标状态（位置、速度、协方差）
- 弹道模块
  - 输入：目标状态、初速、查表补偿
  - 输出：Yaw/Pitch指令、飞行时间、补偿项
- 云台控制模块
  - 输入：Yaw/Pitch指令
  - 输出：执行状态（位置/速度闭环，饱和与限位信息）
- 发射/供弹模块
  - 输入：发射轮转速、供弹速率
  - 输出：当前转速、发射触发状态、卡弹告警
- 通信模块
  - 功能：状态上报与参数回传、异常与重连管理

命名/坐标系约定：右手系；像素(u,v)；相机坐标(x右,y下,z前)；底盘坐标(x前,y左,z上)。
